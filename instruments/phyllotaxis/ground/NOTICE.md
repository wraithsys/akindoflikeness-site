# The ground — provenance

Eight textures from Billy's own library (`dev/shared/hostile-visualiser-audio/
pause`, the TXT_ set, 2026-08-12). His recordings, his rights; nothing here is
third-party. This note exists because the assets gate is a habit, not a
judgement call — every audio or font file on this site carries its provenance
beside it, including the ones that don't strictly need it.

Chosen from the 67 by measurement, not by name: the eight steadiest textures
(loudness range 1.4–7.0 LU) that are also long enough (128–250 s) to give the
grain cloud's golden-Weyl walk real territory. Each texture ships TWICE from
the same loudnorm pass (−23 LUFS, 150 s cap, mono, content-hashed): Opus 64k,
tried first, because OBS's browser source is a codec-stripped Chromium with
no AAC decoder — the rig's own environment; and AAC 96k as the fallback for
Safari, which had AAC in decodeAudioData long before it learned Ogg.

Source WAVs stay out of the repo — 1.8 GB, and the site only ever plays
grains. To change the roster, re-run the encode over different names and
update GROUND in index.html.
